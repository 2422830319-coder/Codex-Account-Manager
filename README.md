# Codex 账号管家（Codex Account Manager）

一个本地运行的 Windows 小工具：**通过导入凭据文件管理多个 Codex 账号，支持一键切换**。浅色界面、单窗口、纯本地运行、不联网上传任何数据。

> ⚠️ **使用前请务必阅读文末的《免责声明与使用风险》。** 本工具与 OpenAI 无任何关联；它只做本地凭据文件的整理与切换，不提供登录能力，也不包含任何绕过认证机制的技术。

---

## 它是什么

Codex 桌面应用（及 CLI）把当前登录状态保存在本地文件 `~/.codex/auth.json`。本工具帮你：

- 把**你自己拥有**的多份账号凭据文件统一收纳成一个"账号库"
- 一键在多个账号之间切换（自动备份、写入校验、失败自动回滚）
- 随时还原到切换前的账号

**支持导入的凭据文件格式：**

| 格式 | 说明 |
| --- | --- |
| 原生 auth.json | Codex 本地认证缓存文件 |
| CPA 扁平 JSON | 形如 `{"type":"codex","access_token":...}` 的导出文件 |
| Sub2 导出 JSON | 含 `accounts` / `credentials` 结构的多账号导出文件 |

> 以上凭据文件均需**由你本人合法持有或已获得明确授权**。本工具不会、也无法为你获取任何凭据。

## 快速开始

1. 安装 [Python 3.9+](https://www.python.org/downloads/)（安装时勾选 *Add python.exe to PATH*），然后安装界面依赖：

   ```
   pip install PySide6
   ```

2. 下载本项目代码，双击 **`启动Codex账号管家.bat`**
3. 把你的凭据文件（.json）直接拖进窗口，或点「导入配置…」
4. 点选要用的账号卡片 → 点「切换到选中账号」

> - 启动器会自动探测 Python 环境（支持 PATH / Python Launcher / 常见安装目录）；找不到时会给出明确提示，窗口不会一闪而过。
> - 切换账号前请先**完全退出 Codex 应用**（工具会自动检测并提醒）。

## 功能一览

- 导入 / 管理多个账号（卡片式账号库、备注名、来源标注、双击改名）。
- 一键切换：自动检测应用是否关闭 → 自动备份当前账号 → 替换 → 写入后校验 → 失败自动回滚。
- 一键还原：回到最近一次切换前的账号。
- 操作日志：每次导入 / 切换 / 还原都有记录，出错原因一目了然。
- 全程本地运行，数据不出本机。

## 数据与文件位置

| 内容 | 位置 |
| --- | --- |
| 程序数据（账号库 / 备份 / 日志） | `%USERPROFILE%\.codex-butler\` |
| Codex 实际使用的账号文件 | `%USERPROFILE%\.codex\auth.json` |
| 每次切换前的自动备份 | `%USERPROFILE%\.codex-butler\backups\` |

**手动回滚方法**：把任意备份目录里的 `auth.json` 复制回 `%USERPROFILE%\.codex\auth.json` 即可。

## 系统要求

- Windows 10 / 11
- Python 3.9 或更高（源码运行方式）
- 已安装并正常使用过 Codex 桌面应用（或 Codex CLI）

## 常见问题

**Q：切换后 Codex 仍显示旧账号？**
A：请先**完全退出** Codex（包括托盘与后台进程）再执行切换；切换完成后重新打开 Codex。工具会在切换前自动检测并提醒。

**Q：双击启动器后看不到窗口 / 提示找不到 Python？**
A：新版启动器会保留窗口显示诊断信息（不会一闪而过）。按提示安装 Python（勾选 *Add python.exe to PATH*）后重试；仍有问题请截图反馈。

**Q：这类工具会导致账号被封吗？**
A：请仔细阅读下方免责声明。使用非官方途径管理账号凭据存在账号受限的风险，请自行评估后决定是否使用。
